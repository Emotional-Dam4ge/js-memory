# Jeu de Memory (Vanilla JS)

Un jeu de mémoire interactif et accessible développé en JavaScript pur (Vanilla JS ES6) dans le cadre du BUT Informatique.

Jouer au jeu en ligne 

Technologies utilisées

HTML5 : Structure sémantique et accessibilité.

CSS3 (CSS Grid) : Mise en page dynamique et responsive sous forme de grille.

JavaScript (Vanilla ES6) : Logique applicative, manipulation du DOM, gestion de l'asynchronisme et événements.

API Picsum Photos : Génération dynamique des images du jeu.

# Fonctionnalités principales

Mélange algorithmique : Permutation aléatoire des cartes via l'algorithme de Fisher-Yates.

Accessibilité (A11y) : Utilisation des attributs ARIA (role="button", tabindex="0") pour garantir la navigation au clavier et la compatibilité avec les lecteurs d'écran.

Gestion asynchrone : Traitement fluide du retournement des cartes non identiques grâce aux fonctions temporelles (setTimeout).

Suivi de partie : Chronomètre dynamique et compteur de coups en temps réel.

Réinitialisation synchrone : Possibilité de relancer une partie à tout moment avec réinitialisation complète des états.
